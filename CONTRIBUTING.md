Contributing to Aprender de Outro Jeito

Thank you for your interest in contributing to Aprender de Outro Jeito!

Our goal is to make educational content more accessible, understandable and adaptable to different learning needs.

How to Contribute

Contributions can include:

- Reporting bugs or technical issues.
- Suggesting accessibility improvements.
- Improving documentation.
- Suggesting educational features.
- Reviewing interface usability.
- Contributing code.
- Sharing ideas about content organization and learning experiences.

Reporting Issues

When reporting an issue, please try to include:

- A clear description of the problem.
- Steps to reproduce the issue, if applicable.
- Expected behavior.
- Actual behavior.
- Suggestions, screenshots or examples, when useful.

Please avoid sharing personal, sensitive or identifiable information about students.

Accessibility Contributions

We particularly welcome suggestions related to:

- Plain language.
- Interface clarity.
- Keyboard navigation.
- Screen reader support.
- Visual accessibility.
- Flexible learning experiences.
- Reducing unnecessary complexity.

Code Contributions

Before submitting code:

1. Describe the change you intend to make.
2. Keep changes focused and easy to review.
3. Test the changes whenever possible.
4. Avoid introducing unnecessary dependencies.
5. Document relevant features or modifications.

Educational Content

Educational content should be accurate, understandable and respectful of different learning needs.

We encourage contributions that improve clarity without oversimplifying concepts to the point of losing their meaning.

AI-generated content should be reviewed before being presented as educational material.

Community Principles

We aim to maintain a respectful, inclusive and constructive environment.

Contributors should:

- Respect different learning experiences and perspectives.
- Avoid stereotypes about neurodivergent students.
- Provide constructive feedback.
- Respect privacy.
- Focus on improving accessibility and usability.

Thank You

Every suggestion, review, contribution and idea can help make learning more accessible.

Thank you for helping us build Aprender de Outro Jeito.
