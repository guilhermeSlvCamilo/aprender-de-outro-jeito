Accessibility Principles

Our Commitment

Aprender de Outro Jeito aims to make educational experiences more accessible, flexible and inclusive.

We recognize that Autism Spectrum Disorder (ASD), ADHD and other learning differences do not represent a single way of learning. Individual preferences, abilities, sensory needs and learning strategies vary significantly.

Our platform seeks to offer flexible options rather than assume that every student needs the same adaptations.

Accessibility Goals

We aim to develop features that support:

- Plain and understandable language.
- Shorter and structured explanations.
- Content divided into manageable sections.
- Flexible learning pace.
- Clear navigation and predictable interfaces.
- Reduced unnecessary visual distractions.
- Responsive interfaces across devices.
- Keyboard navigation.
- Screen reader compatibility.
- Adjustable text size.
- Optional visual and interactive learning resources.

Individual Preferences

Whenever possible, users should be able to choose how they interact with educational content.

Accessibility should not rely on a fixed profile or diagnosis. Students should be able to explore and select learning formats that work best for them.

Educational Responsibility

This project is intended as an educational support tool.

It does not replace teachers, specialized educational professionals, therapists or individualized educational support.

AI-generated educational content, when implemented, should be reviewed, tested and continuously improved to reduce errors, misleading explanations and inappropriate adaptations.

Feedback

We welcome feedback regarding accessibility barriers, usability issues and suggestions for improvement.

Our goal is to continually improve the platform through testing, feedback and collaboration.

Development Status

These principles represent our accessibility goals. Not all features described here are currently implemented.
